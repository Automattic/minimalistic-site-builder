### spec-table

Render the repeated items as label/value pairs with one stable label column and
one stable value column. This is the technical, product, amenity, or factual
idiom: terse, aligned, and easier to compare than cards.

- Build one non-stacking `wp:columns` row per pair, normally 38/62, and put
  `item-pattern__item` on every row. All label columns use the same width.
- Labels are short and visually quieter; values carry the body voice. Use a
  heading block only for the section title, not for every value.
- A subtle between-row separator or bottom border is allowed because the rows
  are genuinely tabular. Do not add card backgrounds, shadows, or large gaps.
- Keep the assigned section archetype as the outer topology and place the
  aligned pair set in the region that archetype gives to the detailed content.
