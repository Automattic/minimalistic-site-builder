### index

Render the repeated items as a numbered or lettered index. The identifier is a
real navigational or sequential cue, not a decorative eyebrow, and it should
form a strong scan column beside the item copy.

- Build one `wp:columns` row per item with a narrow 14-20% identifier column
  and a wide copy column. Put `item-pattern__item` on every row and keep the
  rows compact.
- Use `01`, `02`, … or `A`, `B`, … consistently in the identifier column,
  using the accent font only when the committed direction actually supplies
  one. The copy column holds one heading and one short detail.
- Do not box every row. A shared baseline, whitespace, or a justified
  between-row separator may organize the index.
- Preserve the assigned section archetype as the outer composition; the index
  is the repeated-item structure inside it.
