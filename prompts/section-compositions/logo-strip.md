### logo-strip

Build one row of four to eight client, partner, or publication names as text.
The theme displays these names as small wordmarks.

- Structure: Put at most one lead paragraph of eight words above the row.
- Center that lead paragraph.
- Create one `wp:group` with `"className":"logo-strip"` and `"align":"wide"`.
- Set its layout to `{"type":"flex","justifyContent":"center","flexWrap":"wrap"}`.
- Copy budget: Put four to eight paragraphs in the group, with one name per paragraph.
- Use one to three words per name.
- Use names from the SITE SPEC or section notes.
- If none are supplied, use plausible fictional names from the site's domain.
- Identity: Use the assigned root marker on the top-level group.

Use group and paragraph blocks only.
Keep real company names limited to those in the brief.
The theme sets the font, size, color, and spaces.
- Media: Omit logo images, links, headings, actions, and typography overrides.

- Surface/width: The row runs wide.
- Objective failure: Logo images, multiple name groups, or fewer than four names break this composition.
