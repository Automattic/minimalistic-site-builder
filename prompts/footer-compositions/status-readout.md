**status-readout** — The footer reads as the site's quiet status readout: a
short stack of single-line rows set in the `mono` fontFamily preset at a
small fontSize, lowercase except proper nouns. Each row pairs a muted
one-word label with one verified value — a fact or a link group the SITE
SPEC actually carries; a row whose value the spec does not carry is omitted,
never invented. The credit is the final row in the same voice. No columns,
no display-scale type, no image, and no second typeface anywhere in the
band.
