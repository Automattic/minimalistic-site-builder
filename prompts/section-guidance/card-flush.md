- `flush` (the modern default) — media bleeds to the card's edges; padding wraps only the text. The card `wp:group` gets the box styling (backgroundColor, border radius), `"className":"card-style--flush card-flush"` (the theme ships `overflow:hidden` for `card-flush` so the card's radius clips the media), NO padding of its own, and `"style":{"spacing":{"blockGap":"0"}}` so the media meets the text panel. The image is the FIRST direct child of the card group, with its crop class (below) and NO radius of its own — the card group's radius does all the rounding. ALL text (heading, paragraph, list, buttons) lives in ONE inner `wp:group` with `"className":"card-body"`; that inner group, and ONLY that inner group, carries the card's padding. The hook makes the body consume the remaining height in an `equal-grid`, so a nested `cta-bottom` can align with sibling cards.

Apply this anatomy only to an item with an image. Text-only items must omit `card-style--flush`, `card-flush`, and `card-body`.
Every flush image card requires an explicit non-transparent `backgroundColor` on its outer group. An inherited page surface does not satisfy this contract.
