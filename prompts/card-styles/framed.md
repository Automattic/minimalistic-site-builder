Image-card construction: use `card-style--{{card_style}}` on the outer card group. Keep related text and actions in one inner group with `className:"card-body"` when a wrapper is needed. On equal-card rows this lets a nested `cta-bottom` align with its siblings.

- `framed` — the inset construction: the card group gets `"className":"card-style--framed"`, carries padding on ALL sides, and the media sits inside that padding (polaroid, print, scrapbook moods). Use a literal pixel value for the card radius and ONE uniform literal pixel value for all four padding sides here (not a spacing preset or mixed units), because the corner relationship must be verifiable; write the resulting media radius in pixels too. Corners must be CONCENTRIC: with card radius R and padding P, the media's own radius is max(R − P, 2px) — card radius 24px + padding 32px → media radius 2px; card radius 16px + padding 8px → media radius 8px. NEVER give the media the same radius as its card; equal radii with padding between them read visually wrong.
