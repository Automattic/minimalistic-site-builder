# One CSS device. Strip unbuildable motifs

Directions invent tape corners, twine, araucaria marks, mustard
hairlines. The quality loop banned ornaments as noise. The
honest version is one reviewed device, in CSS, used once. A
paragraph of unbuildable motifs is how we get nothing.

## Change

- Add optional `device`: `none | hairline-rule | section-numeral
  | stamp`. Two or three reviewed utilities. No generated
  imagery. No glyphs as pictures.
- Page plan may place it on at most one band.
- Everything else in the description (twine, tape, rotated
  Caveat) is stripped at normalize. If it is not in the catalog,
  it is not a promise.

## Out of scope

AI-drawn flourishes. A device on every heading. Bringing back
eyebrows as default dressing.
